Documentação interativa

Referência da API de cursos e alunos

Esta API foi feita para a atividade prática: rotas GET, respostas em JSON com jsonify e dados guardados em listas Python. Não há banco de dados. Use os blocos Experimentar para chamar as rotas ao vivo neste servidor.

Base URL
Formato
JSON · UTF-8
Autenticação
Nenhuma
Persistência
Memória (reinicia com o servidor)

Modelos

Cada recurso é um dicionário Python serializado para JSON. Os campos abaixo são os que a API devolve hoje.

Curso

Campo Tipo Descrição
id integer Identificador único do curso
nome string Nome do curso
carga_horaria integer Carga horária em horas

Aluno

Campo Tipo Descrição
id integer Identificador único do aluno
nome string Nome completo
turma string Turma (ex.: 3A)
GET / status

Health check pedido no enunciado. Confirma que o servidor Flask está respondendo. Sempre retorna o mesmo JSON.

Resposta 200

{
  "mensagem": "API funcionando!"
}
GET /cursos cursos

Devolve a lista completa de cursos cadastrados na memória. IDs atuais: 1, 2 e 3.

Resposta 200

[
  {"id": 1, "nome": "Python Básico", "carga_horaria": 40},
  {"id": 2, "nome": "Desenvolvimento Web", "carga_horaria": 60},
  {"id": 3, "nome": "Banco de Dados", "carga_horaria": 40}
]
GET /cursos/<int:id_curso> cursos

Busca um curso pelo identificador numérico da URL. Se o id não existir na lista, a API responde 404 com uma mensagem clara.

Parâmetro de caminho

Nome Tipo Obrigatório Descrição
id_curso integer sim ID do curso. Exemplos válidos: 1, 2, 3.

Resposta 200

{
  "id": 1,
  "nome": "Python Básico",
  "carga_horaria": 40
}

Resposta 404

{
  "erro": "Curso não encontrado"
}
GET /alunos desafio

Lista os alunos cadastrados. Cada item tem id, nome e turma. Há pelo menos três registros.

Resposta 200

[
  {"id": 1, "nome": "Ana Souza", "turma": "3A"},
  {"id": 2, "nome": "Bruno Lima", "turma": "3B"},
  {"id": 3, "nome": "Carla Mendes", "turma": "3A"},
  {"id": 4, "nome": "Diego Alves", "turma": "3C"}
]
GET /alunos/<int:id_aluno> desafio

Devolve um aluno específico. IDs válidos hoje: 1 a 4. Qualquer outro número gera 404.

Parâmetro de caminho

Nome Tipo Obrigatório Descrição
id_aluno integer sim ID do aluno na lista em memória.

Resposta 200

{
  "id": 2,
  "nome": "Bruno Lima",
  "turma": "3B"
}

Resposta 404

{
  "erro": "Aluno não encontrado"
}

GET / continua sendo o JSON de status. Esta página em /docs é só a documentação. Prints de entrega ficam a cargo do aluno.
